Entry for the make.fun competition **"The Word You'd Delete From the Dictionary"** — one word you'd erase from the dictionary forever.

The word: **irregardless** — a word that was never a word, finally deleted by the dictionary itself.

## How it works

`main.ts` writes the single word to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt` when set).
